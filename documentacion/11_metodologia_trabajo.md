# Metodología de Trabajo

El equipo trabaja con entregas parciales semanales, siguiendo el cronograma del curso (03_planificacion.md),
que ya funciona como una serie de entregas de una semana con un objetivo propio cada una. No se
arma un esquema de sprints aparte porque sería duplicar algo que el cronograma ya define.
Cada semana tiene tres momentos:
1. Reparto (inicio de semana): se revisan las tareas de la semana y se asigna un responsable
único a cada una. Queda cargado en el tablero Kanban (S2_03_kanban.md).
2. Ejecución (durante la semana): cada uno trabaja su tarea por separado, comiteando avances
chicos en vez de dejar todo para el final.
3. Integración (antes del corte semanal): revisión cruzada rápida entre el equipo, para que las
tareas de la semana no queden inconsistentes entre sí.
El tablero Kanban es la referencia de estado del equipo en todo momento.
